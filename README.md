# Лабораторная работа №2

## Цель работы

Изучение основ HTML и CSS. Разработка многостраничного веб-сайта с использованием HTML для создания структуры страниц и CSS для их оформления.

## Описание проекта

**DS Mentor** — информационный веб-сайт, посвящённый индивидуальному и групповому менторству в области Data Science.

Сайт предоставляет информацию о форматах обучения, услугах, профессиональном опыте ментора и результатах участников программы.

Проект состоит из четырёх взаимосвязанных HTML-страниц.

## Структура сайта

1. **Главная (`index.html`)** — общая информация о менторстве в Data Science, его целях и основных этапах обучения.
2. **Виды услуг (`mentorship.html`)** — описание форматов менторства, таблица стоимости услуг и ссылка для записи на консультацию.
3. **О менторе (`mentor.html`)** — информация о профессиональном опыте ментора, его специализации, навыках и используемых технологиях.
4. **Успешные кейсы (`cases.html`)** — таблица с результатами участников менторства, компаниями и типами трудоустройства.

## Используемые технологии

- **HTML5** — создание структуры и содержимого страниц.
- **CSS3** — оформление элементов, настройка цветов, шрифтов и отступов.
- **Flexbox** — организация навигационного меню.
- **Git и GitHub** — контроль версий и хранение проекта.

## Реализованные возможности

- Навигация между четырьмя страницами.
- Использование блочных и строчных HTML-элементов.
- Семантическая HTML-разметка.
- Отображение изображений.
- Использование нумерованных и маркированных списков.
- Таблицы с информацией об услугах и успешных кейсах.
- Подключение отдельного CSS-файла.
- Использование различных CSS-селекторов.
- Выравнивание содержимого таблиц по левому краю, по центру и по правому краю.
- Единое цветовое оформление страниц.
